### B. Discovered Issues

**P2 — Pending voice joins outlive terminal session execution.** `JoinVoice` waited on its own context/result channel, while `Run` did not signal that channel on final exit. The public regression confirmed a join reached the local Gateway, cancelled only the run context, observed `Run` return, then received `context deadline exceeded` from the join rather than the existing closed error. The controlled lifecycle regression found no notification for an empty queue and an old queued grant for a full queue. **Resolved:** final run cleanup signals pending voice joins with `gateway.ErrClosed` (already exposed as `micup.ErrGatewayClosed`).

Transient reconnects remain within the run loop and do not execute final cleanup. Established grants/LiveKit room lifecycle are not changed.
