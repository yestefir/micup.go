### B. Discovered Issues

1. **P1 — Mutable query captured by iterator closure.** Affected `src/rest/iterate.go`, `EachMessage` and `EachAuditLogEntry`. Pagination updated the parameter outside the iterator invocation. A second traversal of a three-item fixture returned only its final item, dropping two earlier items. Concurrent consumers wrote/read the same query fields. Pre-fix `go test -race` emitted actual DATA RACE traces at original lines 43/45 and 121, including conflicting reads at lines 22 and 108. **Resolved:** capture the initial query, then copy it into each invocation.
2. **P1 — No cursor progress check.** Affected `EachMessage`, `EachAuditLogEntry`, `EachGuild`. A full page always caused another request, even when the response repeated its final ID. Four local fixtures deliberately returned the same full page and failed the third request to prevent a runaway test. All four pre-fix scenarios reached that cutoff; all fixed scenarios terminate after two requests without an API error. **Resolved:** stop on empty or unchanged next cursors, following existing member/thread iterator conventions. This does not promise deduplication or detection of arbitrary alternating cursor cycles.
3. **P2 — Optional voice verification unavailable.** FFmpeg is absent and `LIVEKIT_TEST_BINARY` is unset; two integration tests skip. **Unresolved validation gap**, not a demonstrated voice defect.
4. **P3 — Windows checkout line endings fail formatting.** 124 existing Go files have CRLF line endings while gofmt emits LF; Git has `core.autocrlf=true`. Every Go file was checked through a normalized temporary copy: zero formatting differences beyond line endings. Changed files are gofmt clean. **Unresolved environment/repository-policy issue**; unrelated files were preserved.

Webhook authorization/name-length inconsistencies and retry-duration conversion are recorded as investigation candidates, not confirmed vulnerabilities or platform failures.
