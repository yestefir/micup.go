### B. Discovered Issues

**P1 — Saturated request queues silently discard member responses.** `src/session/members.go`, `deliverChunk` used a nonblocking send with an empty default branch. A request's queue has 16 slots. When a producer fills that queue before the request goroutine runs, the next data, completion or rate-limit error is discarded. A lost middle page followed by completion can appear successful but incomplete; a lost terminal response can leave the request waiting until its caller context expires.

Evidence: controlled tests fill the 16 slots and send a 17th middle/final chunk. Both pre-fix cases produce no failure notification, and accept a later successful completion despite the lost response. Both now produce an explicit error and ignore later responses for the retired request. **Resolved.** The condition is deterministically demonstrated; its frequency in production is not measured, and no production incident is asserted.

Terminal-session-shutdown behavior remains a separate unverified candidate; transient/resumable disconnect semantics were not changed. Existing gaps remain: two optional voice tests skip and 119 unrelated CRLF files fail whole-checkout formatting (120 before formatting the modified source).

### C. Applied Changes

- `src/session/members.go`: keep lookup/send/overflow retirement under the existing mutex so concurrent deliveries cannot reuse a retired queue. On saturation, remove the nonce, nonblockingly free one buffered slot if necessary, and enqueue an error stating that the member list is incomplete. The request loop already returns collected members with a received error, and its deferred cleanup releases its in-flight slot. Only this delivery path produces into the private queue; readers can only free capacity, so the reserved error send does not wait for a consumer.
- `src/session/members_delivery_test.go`: two overflow scenarios (middle/final), rejection of late completion, unaffected independent requests, normal ordered delivery through capacity, and ignored unknown/cancelled nonces.
- `docs/gateway.md`: documents partial results plus error on response-buffer saturation.
- Updated required audit files/report. No public API or dependency change, unbounded queue, background worker, production action or scheduler edit.
